### Опис вимог до INPUT-потоків інтерфейсу користувача

| FR    | NFR    | Засіб INPUT-потоку                                   | Особливості використання                                                                                                       |
| ------| -------| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| FR1.1 | NFR1.1 | Сенсорний екран смартфона                            | Введення даних користувача: вага, зріст, вік, алергії, ціль (схуднення/набір ваги) через інтерактивні поля та випадаючі списки |
| FR1.2 | NFR1.2 | Мікрофон (голосове введення)                         | Альтернативний спосіб введення даних (через голосові команди, розпізнавання мовлення)                                          |
