### Опис основних нефункціональних вимог, не пов’язаних з інтерфейсом користувача

| FR | NFR | Тип NFR | Опис NFR |
|----|------|-----------|-----------|
| FR1 | NFR3.1 | Time Performance | Максимальний час генерації персоналізованого плану харчування — не більше 2 секунд після введення даних користувача |
| FR2 | NFR3.2 | Time Performance | Максимальний час обчислення рівня самоповаги — 1 секунда після обробки досягнень |
| FR3 | NFR3.3 | Time Performance | Час оновлення стрічки новин — не більше 3 секунд при активному інтернет-з’єднанні |
| - | NFR4.1 | Hardware Interface | Підтримка сенсорів носимих пристроїв (годинники, фітнес-браслети) для зчитування показників здоров’я через Bluetooth |
| - | NFR5.1 | Software Interface | Інтеграція мобільного застосунку Android із зовнішніми сервісами через API (Google Fit, Binance Pay, Edamam, OpenWeatherMap) |
| - | NFR6.1 | Data Transfer | Мінімальна швидкість передачі даних — 1 Mbps для стабільного завантаження контенту; підтримка Wi-Fi, 4G та 5G |
