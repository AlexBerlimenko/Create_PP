### Опис основних нефункціональних вимог, не пов’язаних з інтерфейсом користувача

| FR       | NFR        | Тип NFR           | Опис NFR |
|----------|------------|-------------------|---------|
| FR1      | NFR3.1     | Time Performance  | Максимальний час генерації харчового плану — 2 секунди після надання даних |
| FR2      | NFR3.2     | Time Performance  | Максимальний час обчислення рівня самоповаги — 1 секунда після введення досягнень |
| FR3      | NFR3.3     | Time Performance  | Час оновлення стрічки новин — не більше 3 секунд при наявності з’єднання |
| -        | NFR4.1     | Hardware Interface| Підтримка сенсорів носимих пристроїв (годинник, фітнес-браслет) для отримання даних про стан здоров'я |
| -        | NFR5.1     | Software Interface| Використання API OpenWeatherMap для персоналізації порад щодо активності |
| -        | NFR6.1     | Data Transfer      | Мінімальна швидкість передачі даних — 1 Mbps для стабільного завантаження контенту; підтримка Wi-Fi та 4G/5G |
