### Словник атрибутів об'єктів

| Об'єкт              | Атрибут                  | Короткий опис                                      | Тип       | Обмеження                  |
|---------------------|--------------------------|----------------------------------------------------|-----------|----------------------------|
| Користувач          | ім’я                     | Ім’я користувача                                   | String    | не порожнє                 |
| Користувач          | вік                      | Вік користувача                                    | Integer   | > 0                        |
| Користувач          | алергії                  | Перелік алергій                                    | String    | може бути порожнім         |
| Користувач          | ціль                     | Ціль харчування (схуднення/набір маси)             | String    | одне з допустимих значень  |
| ДаніПроЗдоров’я     | вага                     | Вага користувача                                   | Float     | > 0                        |
| ДаніПроЗдоров’я     | зріст                    | Зріст користувача                                  | Integer   | > 0                        |
| ДаніПроЗдоров’я     | індекс_маси_тіла         | Розрахований ІМТ                                   | Float     | > 0                        |
| ДаніПроЗдоров’я     | рівень_активності        | Рівень фізичної активності                         | String    | одне з допустимих значень  |
| ДаніПроЗдоров’я     | дієтичні_обмеження       | Обмеження в харчуванні                             | String    | може бути порожнім         |
| ПланХарчування      | сніданок                 | Рекомендований сніданок                            | String    | не порожнє                 |
| ПланХарчування      | обід                     | Рекомендований обід                                | String    | не порожнє                 |
| ПланХарчування      | вечеря                   | Рекомендована вечеря                               | String    | не порожнє                 |
| ПланХарчування      | калорійність             | Загальна калорійність                              | Integer   | > 0                        |
| Рекомендації        | обсяг_води_на_день       | Рекомендована кількість води на день               | Float     | > 0                        |
| Рекомендації        | фізична_активність       | Рекомендована активність (хв/день)                 | String    | не порожнє                 |
| Досягнення          | кількість_тренувань      | Кількість тренувань за період                      | Integer   | ≥ 0                        |
| Досягнення          | виконані_вправи          | Назви виконаних вправ                              | String    | може бути порожнім         |
| Досягнення          | нагороди                 | Отримані нагороди                                  | String    | може бути порожнім         |
| Самоповага          | рівень                   | Оцінка самоповаги                                  | Float     | від 0 до 10                |
| Самоповага          | впевненість              | Суб’єктивна оцінка впевненості                     | String    | не порожнє                 |
| ТанцювальніПодії    | назва                    | Назва танцювальної події                           | String    | не порожнє                 |
| ТанцювальніПодії    | тип_танцю                | Тип танцю (сальса, хіп-хоп тощо)                   | String    | одне з допустимих значень  |
| ТанцювальніПодії    | дата_проведення          | Дата проведення події                              | Date      | не порожнє                 |
| ТанцювальніПодії    | місце_проведення         | Локація проведення                                 | String    | не порожнє                 |
