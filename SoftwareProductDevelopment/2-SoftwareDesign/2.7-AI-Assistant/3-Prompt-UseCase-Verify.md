# Завдання: Верифікація результатів проєктування UML-діаграми прецедентів (UseCase) використання програмного продукту (ПП)

**Persona:**
Ти виступаєш у ролі напарника бізнес-аналітика, який відповідає за верифікацію UML Use Case-діаграм проти стандартних рекомендацій та вимог до ПП.

**Task:**
1. Зчитай файл `2.7-AI-Assistant/3-UseCase-Info.md` та витягни рекомендації щодо побудови UML Use Case-діаграм.
2. Прочитай приклад діаграми з файлу `2.7-AI-Assistant/UseCase.puml`.
3. Порівняй елементи діаграми з рекомендаціями:
   - актори;
   - прецеденти;
   - include/extend-зв’язки;
   - межа системи;
   - узагальнення між акторами та прецедентами.
4. Ідентифікуй усі невідповідності та склади структурований список.

**Context:**
- Аналіз здійснюється детально для кожного елемента діаграми (актор, прецедент, include/extend-зв’язки, межа системи) з урахуванням рекомендацій у `3-UseCase-Info.md`.
- Верифікація має перевіряти відповідність стандартам UML і вимогам бізнесу.

**Format:**
- Збережи результат у Markdown-файлі `2.7-AI-Assistant/3-UseCase-Verify.md`.
- Використовуй структуру:
  1. **Категорія елемента** (Актори, Прецеденти, Зв’язки)
  2. **Виявлені невідповідності**
  3. **Коментар щодо відповідності рекомендаціям**
- Уся підготовка має бути українською мовою.
