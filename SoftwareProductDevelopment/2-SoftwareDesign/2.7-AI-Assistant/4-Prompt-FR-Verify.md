# Завдання: Верифікація результатів визначення функціональних вимог до програмного продукту (ПП)

**Persona:**
Ти виступаєш у ролі напарника бізнес-аналітика, який відповідає за перевірку якості функціональних вимог до ПП згідно зі стандартом ISO/IEC/IEEE 29148:2011.

**Task:**
1. Ознайомся з рекомендаціями щодо формулювання функціональних вимог, які наведено у файлі `2.7-AI-Assistant/4-FR-Info.md`.
2. Прочитай опис функціональних вимог у файлі `1.3.1-FR/README.md`.
3. Для кожної вимоги перевір відповідність наступним критеріям якості:
   - Атомарність
   - Завершеність
   - Необхідність
   - Однозначність
   - Незалежність від реалізації
   - Здійсненність
   - Узгодженість
   - Відстежуваність
   - Перевіряємість
4. Визнач для кожної вимоги, чи дотримано кожен критерій.
5. Склади структурований звіт з результатами перевірки.

**Context:**
- Аналіз має бути **дослівним**: кожна вимога перевіряється на наявність або відсутність кожного критерію.
- Особливу увагу приділи відповідності синтаксичному шаблону: `[Subject] [Action] [Object] [Constraint] [Value]`.
- Верифікація має бути корисною для вдосконалення вимог перед передачею в розробку.

**Format:**
- Збережи результат у Markdown-файлі `2.7-AI-Assistant/4-FR-Verify.md`.
- Структура звіту:
  1. **Вступ**: короткий опис мети перевірки та джерел.
  2. **Методологія**: посилання на стандарт ISO/IEC/IEEE 29148:2011 та файл `4-FR-Info.md`.
  3. **Результати перевірки**: таблиця, де для кожної вимоги (FRi) вказано:
     - Ідентифікатор вимоги (FRi)
     - Відповідність кожному критерію (`Так` / `Ні` / `Частково`)
     - Коментарі або цитати з вимоги для обґрунтування
  4. **Загальний висновок**: перелік основних проблем і рекомендації щодо покращення.

- Уся підготовка має бути українською мовою.
