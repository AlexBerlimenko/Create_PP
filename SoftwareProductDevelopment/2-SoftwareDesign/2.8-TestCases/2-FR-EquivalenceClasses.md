# Класи еквівалентності для методу `генерувати_план()`

## За параметром **вага** (тип: дійсне число, межі: 30.0–200.0 кг)

| Опис вхідних умов | Правильний/неправильний клас еквівалентності | Опис значень вхідних даних |
| :--- | :--- | :--- |
| 1) Вага в межах 30.0–200.0 кг | Правильний | `вага = 75.5` |
| 2) Вага < 30.0 кг | Неправильний | `вага = 29.9` |
| 3) Вага > 200.0 кг | Неправильний | `вага = 200.1` |
| 4) Вага = null | Неправильний | `вага = null` |

## За параметром **ціль** (тип: рядок, допустимі значення: "схуднення", "набір маси", "підтримка")

| Опис вхідних умов | Правильний/неправильний клас еквівалентності | Опис значень вхідних даних |
| :--- | :--- | :--- |
| 1) Ціль дорівнює одному з допустимих значень ("схуднення", "набір маси", "підтримка") | Правильний | `ціль = "схуднення"` |
| 2) Ціль не дорівнює жодному з допустимих значень | Неправильний | `ціль = "бігати"` |
| 3) Ціль = null | Неправильний | `ціль = null` |
