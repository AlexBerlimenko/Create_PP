### Опис функціональних вимог


| FR | Опис функціональної вимоги |
|----|----------------------------|
| **FR1** | Отримання персоналізованого плану харчування |
| FR1.1 | Користувач передає свої дані про здоров’я (вага, зріст, вік, цілі тощо). |
| FR1.2 | Програмний продукт аналізує надані дані про здоров’я. |
| FR1.3 | Програмний продукт формує персоналізований план харчування. |
| FR1.4 | Програмний продукт надає користувачеві персоналізований план харчування. |
| FR1.5 | Користувач отримує можливість підтримувати фізичне здоров’я за допомогою плану харчування. |
| **FR2** | Оцінка рівня самоповаги |
| FR2.1 | Користувач передає інформацію про свої досягнення в галузі здоров’я та танців. |
| FR2.2 | Програмний продукт аналізує надані досягнення. |
| FR2.3 | Програмний продукт оцінює рівень самоповаги користувача. |
| FR2.4 | Програмний продукт надає користувачеві оцінку його рівня самоповаги. |
| FR2.5 | Користувач отримує можливість відчувати себе впевненим і цінним. |
